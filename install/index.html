Install on Android

Subwayfers comes as an APK file, so Android will ask for one quick permission the first time.

  1. Download the fileTap “Download for Android” to save Subwayfers.apk.
  2. Open itIf Android blocks it, allow installs from your browser or file manager when prompted.
  3. Tap InstallOpen Subwayfers from your home screen and hit Play.
